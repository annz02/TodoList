# TodoList

一个基于 **Vue 3 + TypeScript + Vite + Tauri** 构建的现代化桌面端待办事项管理应用。

TodoList 致力于提供简洁、高效、美观的任务管理体验，帮助用户轻松规划每日任务、管理时间安排，并通过桌面通知及时提醒重要事项。

## ✨ 功能特性

- 📅 **任务管理**
  - 创建、编辑、删除任务
  - 支持任务起止时间设置
  - 日历与时间选择器管理任务周期

- 📌 **任务分类**
  - 今日任务
  - 已完成任务
  - 全部任务

- ⌨️ **快捷键操作**
  - `Ctrl + N` 新建任务
  - `Ctrl + S` 保存任务
  - `Ctrl + E` 编辑任务
  - `Ctrl + D` 删除任务
  - `Ctrl + W` 关闭窗口

- 🎨 **个性化主题**
  - 支持深色模式
  - 自定义主题配色
  - 高颜值现代化 UI 设计

- 🔔 **桌面提醒**
  - 支持系统通知
  - 定时提醒重要任务

## 🛠 技术栈

- **Frontend**
  - Vue 3
  - TypeScript
  - Vite
  - Pinia

- **Desktop Framework**
  - Tauri
  - Rust

- **UI / Style**
  - 响应式布局
  - 自定义主题系统
